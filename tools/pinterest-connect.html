Pinterest 연결

Verdict Picks 자동 핀을 내 Pinterest 계정에 연결하는 한 번짜리 페이지입니다. 코드와 비밀값은 어디로도 보내거나 저장하지 않습니다(앱 ID만 이 브라우저에 기억해 둡니다).

1. 앱 ID를 넣고 승인하기

Pinterest 로그인 화면이 나오면 블로그 핀을 올릴 계정으로 로그인하고 허용(Give access)을 누르세요. 끝나면 이 페이지로 돌아옵니다.

✅ 승인 완료 — 일회용 코드

  1. GitHub → Actions → Pinterest pins 열기
  2. 오른쪽 Run workflow → mode: connect 선택 → code 칸에 붙여넣기 → Run workflow
  3. 1분 뒤 초록 체크가 뜨면 연결 완료입니다.

코드는 한 번만 쓸 수 있고 몇 분 뒤 만료됩니다. 바로 실행하세요. 코드는 앱 비밀키 없이는 쓸모가 없어서, 채팅이나 저장소에 남기지 않는 한 안전합니다.

다시 시작해 주세요

이 창에서 시작한 승인 요청이 아니어서 코드를 표시하지 않았습니다(다른 사이트가 보낸 요청을 막기 위한 확인입니다).

승인이 되지 않았습니다

앱 설정에 넣을 Redirect URI

Pinterest 개발자 앱의 Redirect URIs에 위 주소를 한 글자도 다르지 않게 등록해야 승인이 됩니다. 전체 설정 순서: 저장소의 daily/pinterest-setup.md
