Only the owner of the YouTube channels Korean Musical Folktales and 가성비리빙연구소. The tools are not available to anyone else.

What data the tools access

  • YouTube data of the owner's own channels through the YouTube API Services: videos, playlists, captions, thumbnails, comments, and YouTube Analytics reports.

How the data is used

Only to upload and manage the owner's own videos, check comments, and measure the owner's own channel performance. Data is not sold, not shared with third parties, and not used for advertising.

Storage

Access tokens are kept privately by the owner. Analytics numbers are kept only as long as needed for the owner's reports.

YouTube and Google

The tools use YouTube API Services. By using them you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be removed at any time at Google Account → Third-party connections or through the Google security settings page.
