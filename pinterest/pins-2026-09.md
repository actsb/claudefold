## One-time setup (about 10 minutes)

1. **Business account** (free, unlocks analytics and website claiming): Pinterest → Settings → Account management → *Convert to a business account*.
2. **Claim the blog**: Settings → *Claimed accounts* → Websites → Claim → choose **Add HTML tag** → copy the `<meta name="p:domain_verify" …>` line.
   In Blogger: Theme → ⋮ → *Edit HTML* → paste the line directly after `<head>` → Save → back in Pinterest press *Verify*.
   (Blogger cannot host an HTML verification file, so the meta tag is the only method that works.)
3. **Rich Pins** (pulls the post title and description onto every pin automatically): open https://developers.pinterest.com/tools/url-debugger/ , paste one post URL, *Validate*, then *Apply*. Blogger prints Open Graph tags by default, so this should pass first time.
4. **Board description** for Best of Amazon 2026 (paste into Edit board):
   > Honest buying guides to the most-wanted products on Amazon US: robot vacuums, wireless earbuds, smart glasses, power stations and the Best Sellers everyone is talking about. Best pick first, real owner reviews, no jargon. From Verdict Picks.

## Two ways to publish each pin

**A. Fastest (20 seconds per post):** open the post → scroll to *Save this guide for later* → red **Save to Pinterest** button → Pinterest opens with the image, link and description already filled → choose the board → Save. Then open the pin → Edit → paste the title from below.

**B. Manual upload:** Pinterest → Create → *Create Pin* → drag in `pin.png` → paste Title, Description, Link and Alt text from below → board *Best of Amazon 2026* → Publish.

Pace: one or two pins a day rather than all seven at once, evenings US time. Re-pin each one to a second, more specific board later (e.g. "Home Backup", "Cleaning Tips") for a second round of reach.
