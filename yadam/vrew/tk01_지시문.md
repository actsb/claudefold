# Vrew 작업 지시문 — tk01 「호랑이 은혜」 쇼츠 (Korean Musical Folktales, 영어)

> 이 문서를 **PC의 Claude 데스크톱 앱 새 대화**에 통째로 붙여넣고, Vrew 사용을 허락해 주세요.
> (클라우드 대화는 PC 화면을 조작할 수 없습니다.)

## Claude에게 (데스크톱 앱)
Windows PC의 Vrew(스탠다드 요금제)를 화면 조작으로 다뤄서 아래 쇼츠 1편을 만들어 줘.
- **크레딧 구매·요금제 변경 금지.** 크레딧이 모자라면 멈추고 알려 줘.
- 노래 오디션 없음: 배경음악은 Vrew 무료 음악 중 잔잔한 국악풍/피아노 1곡을 네가 골라.
- 대본·자막 문구는 아래 그대로 쓰고 **Vrew 자동 번역 쓰지 마** (번역은 Claude가 직접 함).
- 끝나면 결과 파일을 `바탕화면\Vrew반입\tk01\out\` 에 저장하고, 사용자에게 구글 드라이브 「영상」 폴더에 올려 달라고 말해 줘.

## 설정
| 항목 | 값 |
|---|---|
| 프로젝트 이름 | tk01_tiger_kindness |
| 화면 비율 | 9:16 세로 (1080×1920) |
| 길이 | 50~58초 (60초 넘기지 말 것) |
| AI 목소리 | 영어, 차분한 남성 내레이터(이야기꾼 톤), 속도 보통 |
| 자막 | **화면 아래쪽, 크게** (흰 글씨 + 검은 테두리, 한 번에 2줄 이내) |
| 장면 전환 | **디졸브 0.5초** (모든 컷 동일) |
| 그림 스타일 | 조선 민화풍 + 따뜻한 수채 조명, 같은 할머니·같은 호랑이가 끝까지 일관되게 (kdh01 호랑이 그림이 프로젝트에 남아 있으면 같은 호랑이 스타일로) |
| 배경음악 | 내레이션보다 훨씬 작게 (약 -20 dB), 마지막 1초 페이드아웃 |

## 마무리 확인 (Claude가 직접 확인)
- 자막이 화면 아래쪽에 크게, 내레이션과 시간이 맞는지
- 장면 전환이 모두 0.5초 디졸브인지
- 할머니·호랑이 얼굴이 장면마다 크게 달라지지 않았는지 (너무 다르면 그 장면만 다시 생성)
- 내보내기: MP4, 1080×1920, 30fps → `바탕화면\Vrew반입\tk01\out\tk01_tiger_kindness.mp4`
