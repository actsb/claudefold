# Vrew 작업 지시문 — pm01·pm02 「암행어사 박문수」 2부작 쇼츠 (Korean Musical Folktales, 영어)

> 이 문서를 **PC의 Claude 데스크톱 앱 새 대화**에 통째로 붙여넣고, Vrew 사용을 허락해 주세요.
> tk01(호랑이)과 같은 대화에서 이어서 해도 됩니다.

## Claude에게 (데스크톱 앱)
Windows PC의 Vrew(스탠다드 요금제)를 화면 조작으로 다뤄서 **쇼츠 2편(1부·2부)**을 만들어 줘.
- **크레딧 구매·요금제 변경 금지.** 모자라면 멈추고 알려 줘.
- 배경음악은 Vrew 무료 음악에서 네가 고름(1부는 긴장감 있는 국악풍, 2부는 밝은 국악풍). 사용자 오디션 없음.
- 대본·자막 문구는 아래 그대로. **Vrew 자동 번역 금지.**
- **두 편의 박문수·소녀·사또 얼굴과 옷이 같아야 함.** 1부에서 만든 인물 이미지를 2부 생성 때 참조 이미지로 써.
- 결과: `바탕화면\Vrew반입\pm01\out\pm01_inspector_part1.mp4`, `바탕화면\Vrew반입\pm02\out\pm02_inspector_part2.mp4`. 끝나면 사용자에게 드라이브 「영상」 폴더에 올려 달라고 말해 줘.

## 공통 설정
| 항목 | 값 |
|---|---|
| 화면 비율 | 9:16 세로 (1080×1920), 30fps |
| 길이 | 각 50~58초 (60초 넘기지 말 것) |
| AI 목소리 | 영어, 차분한 남성 이야기꾼 (tk01과 같은 목소리) |
| 자막 | **화면 아래쪽, 크게** (흰 글씨 + 검은 테두리, 2줄 이내) |
| 장면 전환 | **디졸브 0.5초** |
| 그림 스타일 | 조선 민화풍 + 영화 같은 조명. 인물 고정: **박문수** = 30대 남자, 해진 회색 도포에 낡은 갓(거지 변장), 날카로운 눈 / **소녀 순이** = 10살쯤, 빛바랜 분홍 저고리 / **사또** = 뚱뚱한 중년, 붉은 관복 |
| 배경음악 | 내레이션보다 훨씬 작게 (약 -20 dB), 끝 1초 페이드아웃 |
