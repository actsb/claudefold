# Price Check 기획서: 다나와·에누리·폴센트에서 배운 것과 우리 블로그에 맞춘 설계 (2026-10-17)

## 1. 한 줄 결론
"아마존이 가장 싸다"를 가격으로 보여 주는 비교표는 지금은 규정상 만들 수 없습니다. 대신 한국 비교사이트의 장점 세 가지를 규정 안에서 가져옵니다.
- 다나와의 **정확한 모델 구분**
- 폴센트의 **지금 살까, 기다릴까 판정**
- 와이어커터의 **좋은 가격 기준선**

새 메뉴 **Price Check**(https://acts39.blogspot.com/p/price-check.html)와 각 리뷰 글 안의 "Price check" 섹션으로 만들었습니다. 아마존 공식 API가 열리면(2단계) 실제 아마존 가격과 시각 표시를 더합니다.

## 3. 그대로 따라 할 수 없는 이유 (규정)
1. **아마존 가격은 공식 API로 받은 값만** 표시할 수 있습니다(어소시에이트 정책 §2(b), 2026-04-14). 손으로 옮긴 아마존 가격은 금지입니다.
2. **가격 추적·가격 알림 기능을 사이트에 두면 안 됩니다**(§6(y)). 폴센트·Keepa식 아마존 가격 그래프와 알림은 불가합니다.
3. **아마존 별점·리뷰 수**도 API로 받은 것만 쓸 수 있습니다(§6(t)).
4. **공식 API(Creators API)는 최근 30일 판매 10건 이상**이어야 열립니다. 예전 PA-API 5는 2026년 4~5월에 종료됐습니다. 지금 계정은 판매 0건입니다.
5. **다른 매장 데이터도 제약이 있습니다.**
   - 베스트바이 API 약관은 다른 소매점을 위해 베스트바이 가격을 분석하는 용도를 금지합니다.
   - 월마트 제휴 약관은 월마트를 깎아내리는 비교를 금지합니다.
   - 대부분 매장이 자동 수집(스크래핑)을 금지합니다.
6. **"최저가", "어디보다 싸다" 같은 비교 주장**은 FTC 가격 비교 지침(16 CFR 233)상 날짜가 붙은 근거가 필요하고, 근거가 7일을 넘기면 위험합니다.

## 4. 설계 (1단계: 지금 적용)
- **메뉴:** "Price Check" 페이지 하나. 전체 기준선 한눈표, 분야별(주방·청소·수면·자동차·반려동물·욕실·테크) 카드, "기준선을 정하는 방법", 변경 기록으로 구성합니다.
- **카드 한 장 = 정확한 모델 하나:**
  - 판정 배지: Buy now / Fair price / Wait for a sale
  - Good 가격선과 Great 가격선
  - 정확한 모델과 헷갈리는 모델
  - 판정 이유(날짜 붙은 과거 할인 기록)
  - "다른 매장에서 본 가격 · 확인 날짜"
  - 아마존 "See today's price" 버튼
- **독자 사용법:** 버튼을 눌러 아마존 결제 가격이 Good 선 아래면 좋은 구매, Great 선 아래면 최저 수준입니다. 아마존 가격은 우리 페이지에 쓰지 않고 독자가 아마존 화면에서 직접 봅니다.
- **각 리뷰 글:** 구매 박스 바로 위에 같은 카드로 "Price check" 섹션을 붙입니다. 새 페이지를 늘리지 않으므로 얇은 페이지가 쌓이지 않습니다. 기존 글에는 개선의 날마다 한 개씩 붙어, 한꺼번에 다시 발행하지 않습니다.
- **데이터와 생성기:** 데이터는 `brand/price-check.json`(지금 25개 모델), 생성기는 `scripts/price_check.py`입니다. 아마존 가격이 들어가면 검사에서 걸리도록 정책 검사를 통과해야 발행됩니다.
- **갱신 규칙:**
  - 새 글을 쓰면 그 글의 추천 상품을 항목으로 추가합니다.
  - 개선의 날에는 그 글의 항목을 다시 확인해 판정과 날짜를 고칩니다.
  - 세일 시즌(블랙프라이데이 11월 27일 전후)에는 주 1회 "Wait" 항목을 다시 확인합니다.
  - 확인 날짜는 실제로 다시 확인했을 때만 바꿉니다.

## 5. 2단계: 아마존 API가 열리면 (최근 30일 판매 10건 이후)
- GitHub Actions가 매시간(최소 24시간마다) Creators API로 아마존 가격·재고를 받아 Price Check 페이지와 해당 글에 표시합니다.
- 표시 문구: "Product prices and availability are accurate as of [시각] and are subject to change.", "CERTAIN CONTENT THAT APPEARS ON THIS SITE COMES FROM AMAZON."
- 다른 매장 가격과 나란히 둘 때는 아마존의 최저 새 상품 가격(있으면 중고 최저가도)을 함께 보여 줍니다.
- "아마존이 Good 선 아래" 같은 판정은 그 시각의 데이터로만 자동 표시합니다.
- 갱신에 실패하거나 24시간을 넘기면 아마존 가격을 자동으로 지우고 버튼만 남깁니다.
- 가격 추적 그래프와 알림은 여전히 만들지 않습니다(§6(y)).

## 6. 운영자님께
- 블로거 → 레이아웃 → 페이지 가젯에서 **Price Check**를 메뉴에 체크해 주세요. API로는 메뉴를 바꿀 수 없습니다.
- 집에 있는 제품의 영수증 가격이나 매장에서 본 가격(사진, 날짜)이 있으면 알려 주세요. 가장 강한 근거가 됩니다.
