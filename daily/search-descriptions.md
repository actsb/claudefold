# Search descriptions to enter in Blogger

Blogger uses this text for each post's `<meta name="description">` and its share preview (`og:description`). Without it, Google writes its own snippet and share cards fall back to the blog-wide description.

**Why it is entered by hand:** Blogger offers no programmatic way to set it. API v3 has no such field, the old GData write API was shut down on 2024-09-30, and importing does not set it (see research/blogger-search-description-2026-10-05.md). It can be set only in the Blogger editor, while signed in.

**Where:** blogger.com → Posts → open the post → right-hand panel **Post settings → Search description** → paste → **Update**. (Settings → Meta tags → *Enable search description* must be on; it is.)

**Let Claude do it in your own browser:** in the Claude desktop app, or with Claude in Chrome (both act in your signed-in browser), say: *"Open blogger.com. For every post listed in https://github.com/actsb/claudefold/blob/claude/sharp-lovelace-n7vhzq/daily/search-descriptions.md, open it in the editor, set Post settings → Search description to the text given for it, and click Update."*

Every description is 150 characters or fewer (Blogger's limit). Newest first; the daily Routine adds each new post at the top of the list.
