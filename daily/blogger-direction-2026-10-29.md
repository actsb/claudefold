## 1. 블로거가 해 주는 것과 못 하는 것

| 해 주는 것 | 못 하는 것, 약점 |
|---|---|
| 무료 호스팅과 HTTPS, 트래픽 한도 없음, 서버 관리 불필요 | **검색 순위 혜택 없음.** 구글 서비스라고 우대하지 않음 |
| 사이트맵·피드 자동 생성. 우리 사이트맵에 글이 모두 들어 있음 | 무료 하위 주소(blogspot)는 스팸 사이트가 섞여 있어 SEO가 더 어렵다는 구글 담당자 발언(2026-01) |
| API 자동 발행. 우리 발행 도구가 이것으로 동작 | 검색 설명 입력 API가 없음(손으로 붙여 넣어야 함), 이미지 업로드 API도 없음 |
| 맞춤 도메인 무료 연결 | 플러그인·서버 기능 없음. 이메일 폼·가격 피드·제휴 스크립트는 모두 외부 서비스 |
| 애드센스 연동(수익 탭) | 월별 보관·라벨 페이지가 자동으로 생기고 noindex 없이 열려 있음(10/29 확인: /2026/10/, /2026/) |
| | 자동 스팸 판정으로 블로그가 내려갈 위험(Hip2Save 2009, 2026년 8월 오삭제 보고). 맞춤 도메인이 없으면 복구해도 주소를 잃음 |
| | 프리미엄 광고망(Mediavine·Raptive)을 쓰는 블로거 사이트는 모두 맞춤 도메인 |
| | 구글도 2026년 3~4월에 자사 블로그 일부(Chromium, Security, AdSense)를 blog.google로 옮김 |

**정리:** 블로거는 **돈이 들지 않는 발행 엔진**입니다. **성장 엔진은 아닙니다.** 방문자는 블로거가 아니라 저자 신뢰, 실제 사진, 독자적인 데이터, 외부 링크, 핀터레스트·이메일에서 옵니다.

## 2. 블로거에서 실제로 성공하는 모델
- **대형:** 하루 수십 건씩 올리는 뉴스·구인 사이트(The Hacker News 등). 우리와 사업 구조가 다릅니다.
- **쇼핑 수익형:** 이름과 얼굴이 있는 개인 생활 블로그입니다(Thrifty Decor Chick 등). 공통점은 다음과 같습니다.
  - 맞춤 도메인
  - 직접 찍은 사진
  - 300~1,100단어의 짧은 글
  - 매주 반복되는 시리즈
  - 이메일 구독
  - 핀터레스트가 가장 큰 소셜 유입
  - 아마존 + 월마트·타깃 링크
- **얼굴 없는 긴 "best X" 리뷰 사이트로 성공한 블로거 사례는 찾지 못했습니다.** 지금 Verdict Picks가 이 형태입니다.

## 3. Verdict Picks의 방향
1. **지금은 블로거를 유지합니다.**
   - 발행 도구가 완성돼 있고 비용이 0입니다.
   - 지금 옮겨도 순위 효과는 없습니다.
   - 대신 블로거의 약점을 메웁니다(4장).
2. **역할을 바꿉니다.** "아마존 상품 리뷰 블로그"에서 **"Prof. H의 구매 판단 노트"**로 갑니다.
   - 실제 전문가 저자를 내세웁니다.
   - 공개 데이터로 비교합니다: 리콜, 유지비, 여러 매장 가격.
   - Prof H Lab의 설명 글과 짝을 이룹니다.
3. **결정 시점: 2027년 2월 중순**(아마존 첫 180일 심사 종료) **또는 월 1,000세션 도달 시.**
   - 그때 맞춤 도메인 + 워드프레스(profhlab과 같은 Hostinger) 이전을 다시 판단합니다.
   - 모든 글이 저장소에 있으므로 이전은 언제든 가능합니다.
4. **하지 않을 것:** 지금 이전하기, 블로거 템플릿 대수정, 모든 글 한꺼번에 재발행.
