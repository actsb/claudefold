## 1. 검색으로 확인한 야담 장르의 흥행 공식

검색 결과에 반복 노출된 야담 채널: 조선야담, 마님야담, 반전민담, 야담야담, 별빛야담, 빨간야담, 조선 야담기록소, 야담대감,
야담노트, 야담집, 야담그날밤, 달빛 극장 이야기책, 야담도깨비, 야담만개.

여러 채널이 서로 다른 제목으로 **같은 원형 이야기**를 올리고 있는 소재가 가장 많이 검증된 소재다. 가장 많이 반복된 원형:

| 원형 | 확인된 변형 제목(채널) |
|---|---|
| **전 재산으로 과부(여종)를 산 바보 머슴 → 벼락부자·신분 역전** | 「전 재산 30냥으로 과부 노비를 산 바보 머슴 만복이 이야기」(야담), 「전재산으로 과부 여종을 산 바보 머슴」(반전민담), 「전재산으로 과부 여종을 산 착한 바보 머슴, 그 후 아름다운 반전」, 「버려진 과부를 아내로 품은 머슴, 하룻밤 사이 벼락부자가 된 놀라운 사연」(마님야담), 「전 재산 털어 사온 머슴이 가져온 '이것' 때문에 대박난 과부 마님」 |
| 바보 머슴이 은혜를 베풀고 복을 받음 | 「구걸하던 어린 남매를 거둔 바보 머슴」, 「천재 아기를 주운 바보머슴과 바보여종, 임금님이 직접 찾아온 이유는?」 |
| 지혜로운 며느리/여종이 난제를 풂 | 「청나라 사신 문제를 푼 여종」, 「지혜로운 며느리」 |
| 보쌈·과부 마님·머슴의 인연(성인 코드) | 「처녀 보쌈하려다 과부 보쌈한 바보머슴 칠성이」, 「20년째 과부 마님과 머슴」 |

→ **선정 소재: "전 재산 서른 냥으로 과부 여종을 산 바보 머슴 만복이"** (가장 많은 채널이 재생산한 원형, 고금소총 계열의 해학+권선징악 구조).

## 2. 시니어 시청자가 좋아하는 시나리오 요소 (검색 인용 + 채널 설명 종합)

- **권선징악**: "나이들어 가면 누구나 권선징악 이야기에 몰입" — 악인은 반드시 벌을 받고, 착한 이는 늦더라도 복을 받는다.
- **신분 역전·반전**: 가난한 머슴의 성공, 버림받은 여인의 명예 회복, 암행어사 출두.
- **효(孝)와 은혜 갚음**: 병든 노모, 주먹밥 하나의 은혜, 손주.
- **정직이 복이다**: 잃어버린 돈주머니를 돌려주는 정직한 사람이 나중에 크게 보답받는 구조.
- **시청 습관**: "집안일·운전·설거지하며 틀어 둔다", "안 봐도 사람 소리를 듣고 싶어 틀어 둔다" → 화면 없이 소리만 들어도 이야기가 따라와야 한다(나레이션이 장면을 설명).
- **길이**: 사연 채널 영상은 8분~1시간 30분, 2시간짜리도 시청지속률 45%. 1시간 롱폼이 표준.
- **반전 예고 훅**: 장(章)마다 끝에 "과연 …했을까요?"식 예고.

## 3. 음성·속도·자막 설계 근거

- 고령층은 배속 시청 시 이해·기억 저하가 큼(서울경제 인용 연구). 시니어 사연 채널은 대부분 차분한 나레이션을 **0.85~0.95배 속도**로 쓴다.
- 자막은 "유튜브 자막 한글 글씨가 너무 작다"는 고령 사용자 불만이 많음 → **1080p 기준 64px 굵은 고딕(나눔스퀘어라운드 Bold), 흰 글자+검은 외곽선, 한 줄 20자 내외, 화면 하단**으로 영상에 직접 굽는다(YouTube 자막 크기 설정에 의존하지 않음).
- 문장은 짧게, 존댓말 나레이션("~했습니다", "~였지요"), 가끔 시청자를 직접 부름("여러분").
- 장면 전환마다 나레이션이 장소·인물을 먼저 말해 준다(소리만 듣는 시청자 배려).

## 4. 이 세션에서 쓸 수 있었던 도구와 제약

- 유튜브·구글 TTS·Edge TTS(bing)·HuggingFace가 모두 프록시 정책으로 차단됨. GitHub 릴리스와 PyPI만 열려 있어
  **sherpa-onnx + mimic3 `ko_KO/kss_low`(오프라인 VITS, 한국어 여성 낭독 음성)**로 나레이션을 합성했다.
  속도는 length 기준 0.78배 + 문장 사이 0.55초 쉼(실측 약 6.4자/초).
- ffmpeg 7.0.2(static): libass 자막, zoompan, xfade, overlay, loudnorm 사용. drawtext 없음 → 제목/장 표지는 SVG→PNG로 만들어 오버레이.
- 그림: 프로그램으로 생성한 SVG 플랫 일러스트(민화풍)를 Chromium으로 PNG화, ffmpeg로 컷아웃 애니메이션(패럴랙스, 흔들림, 눈 깜빡임, 대사 중 입 움직임, 카메라 줌/팬).
